# GPT Image 2 caption-pill refinement

Four GPT Image 2 explorations responding to feedback that the first deterministic caption pill was too tall and wide.

1. Tight capsule
2. Soft highlight
3. Editorial strip — recommended direction
4. Custom squircle

The source generations are concept rasters. GPT Image 2 baked a light/checker preview into this batch instead of returning a real alpha channel, so none of these files should be described or shipped as transparent production assets. Once a direction is selected, reproduce its geometry as exact SVG/CSS with the product colour tokens and true transparency.
