# GPT Image 2 — task-first corrections

Third concept pass generated on 2026-08-31 after identifying that the prior
ChatGPT-native style selector and editor were visually calmer but cognitively worse.

## Style comparison

- Reframes the screen as a visual comparison task rather than settings.
- Shows all five presets at equal, useful size on the same frame and sentence.
- Makes each entire preview the control; removes detached radio buttons.
- Keeps Minimal selected with both a border and checkmark, plus adjacent
  `Previewing Minimal` feedback.

## Inline caption editor

- Removes the permanent Scenes / Video / Words three-column mental model.
- Makes video and the current caption the primary surface.
- Places scene navigation and `Caption 2 of 3` directly below the video.
- Opens the correction field immediately beneath the selected word `few`.
- Moves `All scenes`, style, and style comparison into secondary disclosure/actions.

These are GPT Image 2 design concepts only. No application code changed.
