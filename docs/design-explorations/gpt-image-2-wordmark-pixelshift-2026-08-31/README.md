# PixelShift-inspired ClipSubtitles wordmark exploration

Generated as visual direction references with GPT Image 2 on 2026-08-31, using the real PixelShift wordmark and icon as design-language references.

## Directions

1. **Pixel + smooth italic** — closest transfer of PixelShift's block/smooth contrast.
2. **Pixel dissolve system** — adds a reusable CS mark that breaks into timed pixels.
3. **Caption timing cursor** — keeps the wordmark primary and adds a blue timing cue.
4. **CS breakout monogram** — the cleanest standalone product icon and wordmark system.

The `*-transparent.png` files were background-cleaned and verified to contain an alpha channel. The source generations are retained beside them for provenance. These are concept assets, not production masters; a selected direction should be redrawn as deterministic SVG with light/dark variants and tested at navbar/favicon sizes.
