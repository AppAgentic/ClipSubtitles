# GPT Image 2 — ChatGPT-native UI redesign

Second reference-preserving exploration generated on 2026-08-31 after feedback
that the first concepts should be more intuitive and feel more like ChatGPT.

## Design thesis

- Treat each widget as a natural ChatGPT tool result, not a standalone dashboard.
- Use conversational widths, neutral near-black and graphite surfaces, soft
  off-white text, familiar rounded actions, thin dividers, and low visual noise.
- Use ClipSubtitles orange only for the current choice or consequential action.
- Prefer an obvious next action, progressive disclosure, and plain language.
- Preserve every real workflow boundary and avoid invented product claims.

## Material changes from the first GPT Image 2 pass

1. **Upload** uses two explicit ChatGPT-like source rows and explains the next
   conversational action without claiming unsupported capabilities.
2. **Styles** uses one large current preview plus a simple preset list on the same
   source clip, so users compare caption treatment rather than unrelated footage.
3. **Approval** becomes a compact confirmation result with the exact quote in a
   scan-first sequence and no outer checkout/dashboard card.
4. **Progress** becomes an unobtrusive live tool result that communicates background
   work, three stages, cancellation, and credit release without fake ETA.
5. **Editor** keeps a restrained three-pane workspace, aligns scene 2 with the
   selected word and visible caption, and keeps the video visually dominant.

These files are design concepts only. No application code changed in this pass.
