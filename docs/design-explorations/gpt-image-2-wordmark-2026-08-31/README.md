All four source assets are transparent PNGs with alpha. `contact-sheet-light.png` is a review-only composite on a light background so the dark lettering is easy to compare.

Before production use, the selected concept should be redrawn as a deterministic SVG/code-native mark, with separate light/dark treatments and small-size optical corrections.
