# Dashboard concept exploration

Generated with GPT Image 2 on 2026-08-31 from the current ClipSubtitles product brief. These are visual direction studies, not implementation specifications. Any invented labels, integrations, plan details, limits, credit balances, or unsupported features in the images must be discarded during implementation.

## Shared product brief

- Creator-first video library with uploading, caption generation, editing, exporting, and completed states.
- Upload or URL import.
- Word-timed transcription, transcript correction, timing adjustment, caption styles, motion, and preview.
- Captioned video, transparent overlay, and subtitle-file exports.
- Cost review and approval before paid export.
- Recent downloads, quiet credit visibility, understandable retention, help, and secondary developer/agent access.
- Customer language only; no identity-provider names, hashes, IDs, versions, queues, reservations, or infrastructure vocabulary.

## Directions

1. **Editorial production desk** — premium, calm, information-rich library. Strong for existing projects and recent exports; upload and retention occupy too much prime space.
2. **Visual storyboard home** — strongest creator-first overview. The new-video tile, project filmstrip, caption proof, and live preview make the product understandable immediately. It risks becoming horizontally busy.
3. **Focus studio command center** — strongest single-project continuation experience. The large preview and four next actions are exceptionally clear; it is less efficient for users managing many clips.
4. **Calm production flow** — strongest agency and high-volume model. Status bands and next actions scale cleanly, but the right-hand export controls should only appear after a project is selected.
5. **Caption gallery / creative home** — strongest brand expression and caption-style discovery. It makes the output feel desirable, but needs a calmer navigation and a less marketing-like headline for daily use.

## Selected direction

Joe selected **direction 1, Editorial production desk**, on 2026-08-31. The next exploration preserves its warm black, parchment, amber, editorial typography, restrained export history, and information-rich working-desk character while making the selected project and its next creative actions dominant.

The refined dashboard and agent/plugin family are documented in [`design-1-exploration/`](./design-1-exploration/). These remain design studies; implementation should copy the product hierarchy and interaction principles, not invented values or incidental image text.
