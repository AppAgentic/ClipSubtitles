# Design 1 fidelity audit

Reviewed against the seven Design 1 exploration frames on 2026-08-31.

| Surface | Before | After | Notes |
| --- | ---: | ---: | --- |
| Dashboard | 68% | 87% | Restored the compact personal greeting, cream source module, strong current-project hierarchy, video library density and editorial utility panel. |
| AI connections | 63% | 86% | Added the branded CS-to-ChatGPT bridge, stronger connect state and retained the real connection, revoke, prompt, permission and developer paths. |
| Start widget | 42% | 77% | Added a real file-selection surface while preserving host upload and file-library APIs. |
| Style widget | 48% | 82% | Enlarged visual choices, added truthful preset descriptions and retained live preset mutation. |
| Approval widget | 55% | 81% | Strengthened the quote sheet without weakening exact-cost approval or idempotent render requirements. |
| Progress widget | 58% | 82% | Added a connected stage timeline while retaining polling, cancellation and completed downloads. |
| Fullscreen editor | 50% | 76% | Improved scene, video and word/look hierarchy while preserving actual word replacement, style follow-up and fullscreen behavior. |

Overall visual fidelity moved from approximately **55% to 82%**. Functional fidelity remains higher because the implementation deliberately keeps real project data, access control, quotes, tasks, exports and MCP host APIs rather than reproducing invented content from the concept images.

## Deliberate differences

- ChatGPT's outer conversation chrome is host-owned. ClipSubtitles styles only its portable MCP App surface.
- Concept-image names, prices, durations and status values were not copied. Every concrete value comes from current app state or the deterministic preview fixture.
- The generated CS mark is used as a transparent product asset on a warm neutral tile so both letters remain legible on the dark shell. The MCP resource uses a tiny CSS equivalent to stay self-contained.
- The implementation retains all existing destinations and safety controls: upload/import, editor, styles, preview, export quote approval, progress, cancellation, downloads, connection revoke and developer setup.
